## Installation

### Requirements

- A C compiler (gcc)
- [make](https://en.wikipedia.org/wiki/Make_(software)) (optional)

### Building

Clone [this folder](./).

If you have make, you can run `make` to compile the sources and produce an
executable named "asile" in your directory. You can also run `make clean` to
remove all files generated by make.

Else, you can run the following command (assuming gcc is you C compiler) :
```bash
$ gcc TODO
```

## Usage

If you have `example...` a FOLIe file, you can run the following command to
create an ELF file `a.out`
```bash
$ asile example...
```

Asile accepts a list of options, you can see them by using `asile -h` or
`asile --help`. Otherwise a complete list is available in
[OPTIONS.md](./OPTIONS.md)
